Questions
    Setting up voices and microphone

    Samsung phone (Chrome):

    1. Settings → General management → Text-to-speech.
    2. Preferred engine: Speech Recognition and Synthesis from Google.
    3. Tap the gear → Install voice data → download Norwegian Bokmål and English.
    4. Open this page in Chrome, then menu → Add to home screen.

    Windows 11: use Microsoft Edge for the natural voices (Pernille, Finn, Iselin). In Edge: menu → Apps → Install this site as an app.

    Speaking: allow the microphone when the browser asks. Speech recognition needs internet. If it does not work in this browser, type your answer in the box instead.

    Keep the screen on while listening; phones stop speech when the screen locks.
